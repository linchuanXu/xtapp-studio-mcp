# 淘宝闪购

面向 X4 Pro 的竖屏纯触控履约应用，用一张电子纸界面回答“还要多久、现在到哪、是否安全”。演示订单、商品与履约节点均来自本地 TSV，不连接淘宝、盒马或真实用户账户。

- “配送”页按离线时间线演出确认、拣货、接单、取货、配送和送达，并显示最近三条动态。
- “订单”页展示可核对的商品、优惠、实付与经过遮掩的演示地址。
- “安心”页集中说明号码保护、隐私锁屏、温控分袋与送达凭证。
- 顶部轻触或左右滑动切页；底部可重播履约演示或申请设为锁屏。
- 锁屏每 30 秒刷新，只显示 ETA 和模糊化履约状态，主动隐藏商家、商品、金额、地址、联系人与电话号码。

发布素材使用 `app_icon_s`、`app_icon_l`、`splash`、`brand_mark`、`feature_scene`，以及 `delivery_bag`、`store_pin`、`rider`、`route`、`shield`、`check` 等 1bpp XIC key。
