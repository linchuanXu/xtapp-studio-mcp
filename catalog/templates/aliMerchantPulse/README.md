# 淘宝经营快报

面向 X4 Pro 的竖屏纯触控经营看板，把淘宝商家一天最值得看的指标压缩为“成交、商品、推广、待办”四个页面。所有数字均来自本地确定性 TSV 演示数据，不连接淘宝店铺、直通车或真实商家账户。

- “总览”用成交额、订单、待发货、退款和投放 ROI 快速判断店铺健康度，并可轮换今日优先事项。
- “商品”按成交排序，同时提示转化趋势与低库存风险。
- “推广”对比三类计划的消耗、ROI、预算余量和操作建议。
- “待办”聚合补货、发货、加投与售后事项，底部轻触可依次标记完成。
- 顶部轻触或左右滑动切换四页；界面使用黑白 1bpp、高对比线框和大触控区域。

发布素材使用 `app_icon_s`、`app_icon_l`、`splash`、`brand_mark`、`feature_scene`，以及 `trend_up`、`product_box`、`campaign`、`alert`、`check` 等 1bpp XIC key。
