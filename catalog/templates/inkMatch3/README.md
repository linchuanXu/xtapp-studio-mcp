# 果蔬消消乐

面向 X4 Pro 的离线交换式三消游戏。点击两枚相邻果蔬完成交换，横竖三连即可消除；四连、五连与 T/L 形会生成特殊棋子，相邻特殊棋子可组合触发更大的清除范围。

## 玩法

- 7×7 竖屏棋盘，六种果蔬：苹果、葡萄、樱桃、胡萝卜、玉米、蘑菇。
- 30 个关卡分为五章，逐步引入收集、得分、冰层、锁链、石块、掉落菜篮与杂草压力。
- 四连生成横向或纵向火箭，T/L 生成爆炸南瓜，五连生成彩虹果篮。
- 特效之间可以直接交换，产生十字、三行三列、5×5、同类转特效或全盘清除。
- 关卡进度、星级和当前残局保存在 `ctx.state.ink_match3`，不联网、无广告、无内购。

## 墨水屏交互

主要操作为“点第一枚，再点相邻第二枚”。消除过程采用离散事件阶段，不播放高帧率下落动画。

## 工程结构

```text
inkMatch3/
├── index.lua
├── manifest.json
├── domain/        # RNG、棋盘、判定、结算与统一入口
├── data/levels.lua
├── raw/           # 官方 Material Design Icons 源文件与许可证
└── assets/        # 真机 XIC 与预览 PNG
```
