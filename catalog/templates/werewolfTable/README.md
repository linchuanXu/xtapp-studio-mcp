# 《月下狼局》

面向 X4 Pro 竖屏墨水屏的单机标准狼人杀。你与八名 NPC 围坐同桌，通过昼夜行动、完整警长竞选、公开发言、回应、追问、遗言、警徽与放逐投票找出狼人。

这不是在线匹配或真人房间，也不是由剧情指定答案的推理小说。每位 NPC 只获得自己身份允许知道的信息；狼人知道队友，预言家只知道验人，女巫只知道当夜死者，其他玩家只依据公开信息推断。

## 当前实现路线

- 9 人标准规则：3 狼、预言家、女巫、猎人、3 平民。
- 警长竞选与逐票记录、1.5 警徽票、夜晚行动，以及“首轮表态 → 两次追问／回应 → 最终站边 → 公投”的白天循环。
- 公开证据账本：NPC 与玩家的发言、公开声明、站边、改票理由、追问回应和票型都进入同一条公开事实链；秘密身份与夜间信息不会写入其中。
- 可分页证词簿：回看公开发言、验人声明、站边、追问回应、警选、投票与翻牌；右上角图标打开。
- 菜单中的“桌面情报”把存活者、警长、已翻身份、公开验人、当前站边和追问进度汇成一屏；它不会显示任何未公开身份。
- 白天发言时，当前说话者会在舞台右侧显示独立大头像，座位卡同步标记“发言中”；玩家自己的发言策略页也显示自己的头像。
- 玩家普通出局后自动进入观战：剩余 NPC 会完成发言与投票，仍可阅读证词簿直至结算。
- 五套人工调校牌局，覆盖预言家、平民、女巫、猎人和狼人视角。
- 狼人视角支持夜袭、隐藏同伴，以及伪装预言家并公开报验人的白天策略。
- 私有信息有明确反馈：狼人开局与行动时可见同伴；预言家查验后即时获得仅自己可见的阵营结果。
- 每一次追问、投票与技能行动都会先显示“你做了什么／结果如何”的确认回执；回执存在时任意点击只会关闭它，不会误触下一步。
- 每个夜晚结算后会逐项显示公开晨报、死亡翻牌、遗言、猎人开枪与警徽移交，再进入白天发言。
- 结算页公开完整身份，并总结你的身份与胜负、投票命中、站边／追问次数和关键放逐；完整证据链仍可通过证词簿复核。
- 单局状态保存在 `ctx.state`；退出后由宿主恢复。
- 场景、结算卡、桌面事件卡、九个座位头像与舞台半身像已生成原创线稿（`raw/*.png`），经 1bpp 编码入库；换稿规范见 [ASSET_PLAN.md](ASSET_PLAN.md)。

规则、信息边界和牌局设计见 [GAME_DESIGN.md](GAME_DESIGN.md)。人物桌位见 [CHARACTERS.md](CHARACTERS.md)。

## 触控

- 点击中部选项执行行动、选择目标或投票。
- 新开游戏可直接选择五套牌局；切换牌局会创建一局全新的存档。
- 点击对话区域继续听取白天发言。
- 每个选择都只使用当前规则允许的公开目标。
- 点击右上角三线图标打开证词簿；点击面板空白处返回，底部可翻看较早或较新的记录。
