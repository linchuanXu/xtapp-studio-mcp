# 枕上古诗

高中常见必背篇目，按唐、宋、文分列，列表保持文件顺序。正文都是通行全文，不是截句。打开一篇后先朗读；需要时再看注释与今译，或进入遮句背诵，从全部隐藏开始逐行揭开。

进度只记收藏和上次读到哪一篇，不做间隔复习。

**列表**

- **左右 / 左右滑 / 顶部分类**：全部 / 唐 / 宋 / 文 / 收藏。
- **上下 / 点按篇目**：选择并打开。每行是标题，下一行是时代、作者和首句。
- **BACK**：退出应用（列表页不拦截）。

**朗读**

- **左右 / 左右滑 / 底栏「上一篇」「下一篇」**：换一篇。
- **OK / 点正文 / 底栏「注释」**：显隐注释与今译（分开标注）。
- **↓**：正文未完则下翻，底栏上方会出现「还有下文 ↓」；已到底或一屏能读完时进入背诵。底栏「背诵」直接进入。
- **↑**：有滚动则上翻，否则上一篇。
- **点标题或右上 ★**：收藏。
- **BACK / 左上「〈 返回」**：回到列表。

**背诵**

- **OK / ↓ / 点诗句 / 「下一句」**：揭开下一句；全部揭开后按钮变成「重来」，再按一次从头藏起。
- **↑**：收回上一句。
- **左右**：换一篇并重新藏句。
- **BACK / 「〈 返回」 / 「看全文」**：回到朗读，不回列表。
