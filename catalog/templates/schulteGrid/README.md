# 舒尔特方格

注意力训练。首页选规格，训练页只留方格和下一格，结算后看成绩。

点过的数字默认还留在格上，这是原式练法。也可以改成消格。计时从点对第一个数开始。格子和用时的数字是 TTF 转成的点阵，不用系统字。

**首页**

- **规格**：3×3 热身，4×4，5×5 经典，6×6 进阶。
- **顺序**：正序 / 倒序 / 先奇后偶。
- **格上**：留格原式，或消格省力。
- **开始本局 / 说明 / 成绩**。

**训练**

- **点格子 / OK**：点对了进入下一个；点错记一次，格子不重洗。
- **重开**：同一规格重新洗牌。
- **返回 / 回首页**：放弃本局。
- **↑↓←→**：移动焦点。

**结算与成绩**

- 用时、评级、与最佳和上局比较。
- 今日局数、无错连胜、各规格最佳、最近八局。
- 5×5 正序给出常用参考时间。
