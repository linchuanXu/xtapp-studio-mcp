# 元素周期表

X4 Pro **横屏 800×480**。总表单独一屏：顶栏是标题和胶囊「全部 / 必考 / 自测」，族号单独一行，18 列方格只放序数和符号。点开一格后才进详情——标题是「符号 中文名」，右边先读类别和数据，左边是圆角卡片和玻尔（前 20 号）或同族。

- **点格子**：只打开该格。空位按同一周期行吸附，第一周期不会斜插到 Be。
- **点 La / Ac 行标**：分别打开镧、锕。
- **全部 / 必考**：胶囊切换方向键是否只走常考。必考模式下有框是常考、无框只留符号；点按仍可打开任意格子。
- **← → ↑ ↓**：在同行或同列移动焦点。第一周期 H 右键到 He。
- **OK**：总表打开当前格详情；详情页进入自测。
- **点「自测」**：前 20 号自测。进度「3 / 20」，揭开前后卡片布局不动。
- **〈 返回 / BACK**：详情回总表；自测回到进来的那一页。总表不处理 BACK（退出应用）。
