# 1688 采购补货台

面向 X4 Pro 的竖屏触控采购决策 Demo。它把低库存、起订量、供应商报价和预计到货集中到一块适合电子纸快速扫读的面板中。

- 总览页显示缺货风险、采购预算、预计到货和今日建议。
- 补货页可上下滑动浏览 SKU；轻触进入决策页，调整采购数量、比较三档报价并生成采购单。
- 询价页汇总待回复、降价与交期变化；待办页可逐项完成采购动作。
- 所有商品、库存、报价与供应商均为本地 TSV 演示数据，不连接 1688 账户、不下真实订单。

应用只面向 480×800 竖屏 X4 Pro，以触摸为唯一操作路径；所需素材 key 为 `app_icon_s`、`app_icon_l`、`splash`、`brand_mark`、`feature_scene`、`icon_box`、`icon_alert`、`icon_factory`、`icon_truck`、`icon_quote` 和 `icon_check`。
