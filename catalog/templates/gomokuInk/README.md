# 五子棋·墨局

面向 X4 Pro 的可编辑五子棋标准应用：支持 15×15 / 9×9、双人对弈、三档人机、续局、悔棋、认输、计时与按棋盘尺寸记录的战绩。

## 交互

- 触摸：点按棋盘落子；点按难度页或对局页的“返回选局”回到主菜单；点按菜单、难度、暂停和终局操作。
- 按键：方向键移动落点，`ok` 落子或确认，`back` 打开暂停菜单/返回。

## 参考与适配

玩法、优先级和 AI 参数参考 [CrossMux](https://github.com/0x1abin/crossmux) 的 Gomoku 实现（MIT License）。本项目没有复制其 C++ 源码，而是在 XTApp Lua 运行时中重新实现：保留即时胜负拦截、邻域候选、开放连子评分、简单/中等/困难三档策略和相同的 2 / 4 / 6 层配置；AI 落子安排在下一次 tick，避免阻塞电子墨水屏输入回调。

持久状态仅使用 XTApp 契约提供的 `ctx.state`，因此离开应用后可从“继续对局”恢复未结束的棋局。
