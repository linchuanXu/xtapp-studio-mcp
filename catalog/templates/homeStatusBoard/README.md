# 家居状态板

一个为墨水屏桌面准备的离线家居状态板。环境数据、天气和设备状态全部是应用内的模拟快照，**不会联网，也不会连接 Home Assistant**。

- 按 **左右** 或 **上/下**：在全屋与四台设备之间移动焦点。
- 设备聚焦时按 **OK**，或直接点击设备卡：模拟开关空调、加湿器、台灯，以及玄关门锁的锁定/解锁。
- 点击 **回家 / 睡眠** 场景：模拟联动多台设备，并切换环境快照。
- 点击底部 **刷新**：切换下一组本地环境快照。
- 在全屋焦点按 **OK**，或点击顶部环境卡：查看环境、用电、安防与自动化详情；详情页按 **BACK / OK** 返回首页。
- 按 **BACK**：从设备焦点回到全屋概览。
- X4 Pro 支持点击设备、场景、环境卡与底部刷新按钮；X4 Classic 可完整使用按键操作。

未来接入真实服务时，可将 `SNAPSHOTS` 中的固定数据替换为经过适配层整理的实体状态；界面与交互无需改变。

图标素材使用项目已安装的 [Lucide](https://lucide.dev/) 前端图标库（ISC），由 XTApp Studio 转制为设备使用的 1bpp XIC 文件。
