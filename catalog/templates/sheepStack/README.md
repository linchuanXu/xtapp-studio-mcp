# 三羊叠叠乐

一款为 X4 墨水屏重写的叠牌三消游戏。选未被遮挡的棋子；暂存槽中三张相同棋子会消除；第七格仍无法组成三消即失败。

## 操作

- 首页：点“继续第 N 关”恢复当前关卡；点“选择关卡”进入 6×6 关卡页；点“玩法说明”查看规则。
- 关卡页：可点已解锁的关卡；未解锁关卡显示为横线。完成关卡后会自动解锁下一关。
- 对局：点未遮挡棋子；点底部的撤销、移出或提示按钮；长按棋盘暂停。
- 本作仅支持 X4 Pro 触屏，不提供 Classic 或方向键焦点模式。

## 内容

内置 36 个确定性关卡；关卡定义位于 `levels.lua`，与运行时分离。五章难度从 3 层入门叠放推进到 5–6 层的不规则交叉牌面，并逐步引入九种棋子与更多混合组。进度、当前残局、道具与撤销快照保存在 `ctx.state.sheep_stack`。不会连接排名、广告或任何网络服务。

## 难度

本作定位为专家向：第 1 章仅提供一次撤销；第 2 章起不提供撤销、移出或提示。七格暂存槽、同类插入与三消时机保持上游规则，所有关卡都经过纯牌局求解验证。

九种棋子与商店图标为原创黑白线稿（1bpp XIC）。换稿步骤与槽位见 [ASSET_PLAN.md](ASSET_PLAN.md)；不得使用上游或任何未获授权作品的素材。

首页、关卡页、道具、暂存槽与胜负弹层的 UI 线稿已接入；文件名、尺寸与换稿提示词见 [raw/UI_ASSET_PROMPTS.md](raw/UI_ASSET_PROMPTS.md)。
