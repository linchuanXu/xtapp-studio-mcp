# 史纲年表

中国历史公版纲要，按上古、秦汉、隋唐、宋元、明清、近代分列。总表左侧是年代，右侧是朝代或事件名，当前行反色。点开一行看起止年、都城（若有）和两三条口语要点，上方有一条竖轴简图。

只记上次看到哪一条，不做问答，也不套间隔复习。年代写通行说法，说明是原创短句，不抄教材论述。

**总表**

- **左右 / 左右滑 / 顶部分类**：上古 / 秦汉 / 隋唐 / 宋元 / 明清 / 近代。
- **上下 / 点按一行**：选择并打开。
- **BACK**：退出应用（列表页不拦截）。

**详情**

- **左右 / 左右滑**：同一类里上一条 / 下一条。
- **BACK / 左上「〈 返回」**：回到总表。
