# 墨背单词

支持 X4 Pro 的 480×800 竖屏与 800×480 横屏；触摸点按、长按、滑动与上下侧键均可完成复习。

面向 X4 Pro 的触屏优先复习体验：点击明确的“查看答案”按钮翻面，通过“不认识 / 模糊 / 认识”三档评分安排复习；左滑认识，右滑不认识。方向键、OK 与 BACK 保留为完整兜底，上一题误评可立即撤销。

## 学习机制

- 每个词独立保存学习阶段、复习次数、遗忘次数、当前间隔和下次复习日。
- 每日新词可选 5、10、15、20 或 30 个，并优先安排当前词库的到期复习；单轮最多 12 个计划词。开启积压保护后，到期词达到每日新词量时会暂停引入新词。
- “认识”依次把间隔推进为 1、3、7、14、30、60、120 天；“模糊”采用更保守的 1、2、4、7、14、30、60 天；“不认识”会让该词在本轮稍后重现，并从 1 天间隔重新巩固。
- 新词支持稳定乱序、固定顺序、英译中、中译英及混合方向。四级与六级中的重合单词共享同一份学习进度。
- 今日新词、今日复习与连续学习天数由设备本地日期驱动。RTC 未校准时仍可按设置完成一轮新词，但界面明确提示，且不会伪造连续天数或到期日期；时钟恢复后会安全建立下次复习日。
- 进度页区分“学习中”和“已掌握”，显示预计完成天数，并提供收藏词复习与带二次确认的全部进度重置。
- 正常退出应用时，运行时会持久化 `ctx.state`。应用不会宣称每次点击后已立即写入闪存。

## 词条信息

离线内置 4,544 个四级词、3,991 个六级词及 12 个旅行词，每个词条包含词性、音标、精简中文释义和例句。原始字母序会先按难度分组、再以稳定散列打散，避免连续学习大量同首字母单词。两套大词库按每片 200 词拆入 `data/*.tsv`，单轮只读取当前需要的最多 12 条；学习状态只保存真正学过的词，不复制整套词库，因此长期使用也不会让状态文件突然膨胀。

主单词不使用设备默认小字：XTApp Studio 会把项目内 OFL 许可的 Kaisei TTF 栅格化为常规与紧凑两套字母 XIC。较长单词会自动改用紧凑字形，只有含连字符等无法逐字组合的内容才安全回退到系统文字。

中文品牌标题使用 ZCOOL KuaiLe，按钮与首页状态标签使用 Noto Sans SC。所有按钮采用同一套 Tabler Icons 线性图标。生成脚本会把选定 SVG 与标签、边框合成为完整的 1bpp XIC，避免图标、文字和触区在不同设备尺寸下错位。

词库分片由 XTApp Studio 从固定上游提交生成。修改生成规则或升级上游后，在 Studio 中重新生成数据分片。

内置词库的来源、许可和当前离线收录范围见 [NOTICE.md](NOTICE.md)。
