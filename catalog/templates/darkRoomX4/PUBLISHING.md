# 发布门槛｜A Dark Room · 墨水版

当前候选包已通过 X4 模拟运行、打包和本地商店安装验证。平台项目页是本项目的开源交付面；不需要额外建立 GitHub 仓库。

1. 平台项目页必须能公开访问，并包含 `index.lua`、`manifest.json`、`NOTICE.md`、`LICENSE.md`、图标源文件及与包匹配的 `dist/` 发布物。
2. 从平台公开的源码版本完成发布校验。
3. 商店详情页必须粘贴 `STORE_LISTING.md` 中“署名与许可”段落，尤其是上游归属、非关联声明和平台项目页。

发布时确认平台项目页可被普通访客读取；不应把仅本地可访问的路径当作公开源码交付。
