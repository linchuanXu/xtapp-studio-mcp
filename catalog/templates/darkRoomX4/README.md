# A Dark Room · 墨水版

可审计、可编辑的 X4 Pro 社区移植工程。

- `manifest.json`：XTApp API 2.x 应用清单。
- `index.lua`：完整可玩的 Lua 入口和持久化状态。
- `NOTICE.md`：上游归属、商标非关联声明与对应源码位置。
- `LICENSE.md`：Mozilla Public License 2.0 全文。
- `STORE_LISTING.md`：商店标题、文案、图标用途、署名与上架人工检查项。
- `PUBLISHING.md`：公开源码与商店提交的不可跳过发布门槛。
- `UPSTREAM_PARITY.md`：以原作提交为准的完整玩法移植清单；它明确当前哪些系统尚未达到原作体量。

当前候选版已具备房间、村庄经济账本、61×61 荒野、地标探索、战斗、制造器、飞船与碎片云终局的可玩链条。它仍不是“完整复刻”声明：每类地城的独立剧情、完整房间事件状态机、完整命中/冷却表与连续 Space 演出仍在移植；准确状态见 `UPSTREAM_PARITY.md`。

## X4 操作

- 在房间、村庄、小径、荒野、制造器与飞船页，左右切换已解锁页面；上下选择当前账本项目。
- 村庄页 BACK 切换建造、制造、商队、职业与远征账本；职业账本可清空并重新分配村民。
- 荒野中，方向键移动；OK 返回村庄；发现飞船后 BACK 前往飞船页。食物每两步消耗一份，水每步消耗一份。
- 地标页：上下选择深入或撤退，OK 确认；深层可能进入守卫战。
- 战斗中 OK 攻击、↑↓ 切武器、← 吃补给、BACK 使用药草。
- 飞船页依次加固/升级/起飞；碎片云中 ←→ 换道、OK 保持航向。
- 结局页 OK 开始新的一局，BACK 退出。

## 发布前门槛

必须对当前版本执行：静态校验、X4 Pro 运行及存档恢复、XTAPP 打包和本地模拟安装。对外发布时，需使本目录与包内源代码的公开地址保持一致，并保留 NOTICE 与 LICENSE。

生成候选发布包：

前一条写入 `dist/` 下的 `.xtapp`、SHA-256 校验文件和 `release.json`；后一条校验包字节、加密段、版本、SHA-256 与可见源码指纹一致。上架前仍需运行设备/交付测试，并在商店页粘贴 `STORE_LISTING.md` 的许可与源码披露。
