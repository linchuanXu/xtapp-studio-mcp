# 一叩 · 电子木鱼

适配 X4 Classic 与 X4 Pro 的轻量电子木鱼。

- 按 **OK** 或点木鱼：敲击一次。
- **上 / 下**：切换今日目标（27、54、108、216）。
- **左 / 右**：查看上一条 / 下一条短句。
- **BACK**：清零本次打开后的敲击数；累计功德不会清除。

累计功德、当前一轮进度、目标、最长一轮、重置次数与已得墨印会保存在宿主状态中。由于 XTApp 契约没有稳定的日历接口，本应用不伪造“连续天数”，而是记录可验证的完整练习轮次。

每次敲击都会改变内容，而不只是数字：

- 木槌经历**待机 → 抬起 → 落槌（1000ms）→ 回弹**；
- 36 条静心短句按确定性序列轮换，单轮不会机械重复；
- 6 组墨韵与 0–8 粒墨点轮换，九叩聚成一印；
- 首批 15 枚成就按累计、单轮、完成轮次、重启练习与超越目标解锁；新印会以适合墨水屏的静态提示停留 2.2 秒。

画面使用两个独立对象：`woodfish_hero`（团鱼形、空心音孔、斜背击打面与圆垫）与 `mallet_rest` / `mallet_raise` / `mallet_hit`（三帧短柄圆头木鱼槌）。源图是 `raw-woodfish-v3.png` 与 `raw-mallet-frames-v2.png`，均为本项目原创生成；换稿后在 XTApp Studio 中重新编码。

交互方向参考了 [xiwang-online/Electronic-Wooden-Fish](https://github.com/xiwang-online/Electronic-Wooden-Fish) 的开源网页作品，仅借鉴“手动敲击、累计记录”的通用产品思路，不使用其代码、素材或文案。
