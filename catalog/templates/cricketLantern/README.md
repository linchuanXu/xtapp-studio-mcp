# 《灯下促织》

一纸征虫令逼近柴门。你只有三日：交出一头斗虫、揭开账册，或带着家人离开。

这是面向 X4 Pro 竖屏墨水屏的触屏分支文字游戏。取材自蒲松龄《聊斋志异·促织》的征虫困境，但人物、台词、选择、场景与结局均为本项目原创。

## 游玩方式

- 点舞台或对话框继续阅读。
- 每页固定四行正文；出现小三角时可继续翻页，读完才会出现选项。
- 读完一段后，点中部的选项推进。
- 点右上角设置图标查看状态、阅读记录与章节书签。
- 进度由宿主在退出时保存；下次打开会从同一页继续。

## 你会影响什么

| 状态 | 含义 |
| --- | --- |
| 人心 | 肯同你把话说到底、为名字开口的人。 |
| 阿蘅 | 她还愿不愿同你并肩。 |
| 账证 | 能把谎话钉在账上的欠条、副账和旧账。 |
| 虫笼 | 与县衙谈判，或换取片刻平安的筹码。 |

结局包括：短暂保住屋檐的「微火之下」、拿着账册入堂的「堂前斗鸣」、十七户人共同发声的「满街竹笼」，以及与阿蘅离开的「向灯火之外」。结算页会说明这一次路径留下的具体后果，而非只展示数值。
