# 四象限清单

为墨水屏准备的离线任务总览。它使用本地模拟任务，按“重要”和“紧急”分入四个象限；不连接滴答清单或任何在线服务。

- 按 **方向键**：在四个象限之间移动。
- 按 **OK**：进入当前象限的任务列表；在列表中再按 **OK** 才切换所选任务完成状态。
- 按 **BACK**：回到第一个象限。
- X4 Pro 点击象限卡进入列表；点击列表任务左侧的圆形勾选区完成任务。

将来接入真实任务服务时，只需替换 `QUADRANTS` 的数据适配层；视觉结构和设备交互无需改变。

图标使用项目已安装的 [Lucide](https://lucide.dev/) 前端图标库（ISC），并通过 `encode-quadrant-planner-icons.mjs` 转制成 1bpp XIC 素材。
