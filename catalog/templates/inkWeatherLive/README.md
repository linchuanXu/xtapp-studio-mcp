# 墨水天气

为 X4 Pro 与 X4 Classic 设计的联网天气应用。信息层级借鉴苹果天气：当前温度和天气现象是首要内容，随后是逐小时预报、近期趋势，再把 15 天预报、空气质量、预警、生活指数和限行信息放到独立页面。

## 数据

设备只请求一个固定、公开的 HTTP GET 路由：

```text
GET http://193.112.174.92:28473/demo/weather/dashboard/xtapp?city_id=2
```

服务器使用用户已购买的墨迹天气专业版 API，把天气实况、24 小时预报、15 天预报、天气预警、生活指数、空气质量、AQI 预报和限行数据汇总为 `XTAPP_WEATHER_DASHBOARD_V1` 文本。AppCode 和供应商 token 只保存在服务器环境中，不进入 Lua、Manifest 或安装包。

地区选择使用另一个固定路由：

```text
GET http://193.112.174.92:28473/demo/weather/locations/xtapp?parent=0&page=1&page_size=7
```

后端数据来自墨迹天气官网发布的“城市信息 Excel 表”，覆盖 34 个省级地区以及全国区县和天气点，共 6,595 个可查询位置。设备按“省级地区、城市、区县”逐层请求，每次最多返回 7 项；界面只展示地区名称，供应商 CityID 始终作为内部字段使用。用户选择的位置保存在 `ctx.state`，下次启动会直接恢复。源表中的海外城市不属于当前阿里云 CityID 套餐的有效范围，因此不会显示成可选却无法查询的位置。

## 操作

- `左 / 右`：切换“天气、未来、生活”三个页面。
- `OK`：打开地区选择；按“省级地区、城市、区县”逐层进入，选择后立即刷新。
- 地区选择中使用 `上 / 下` 选择，`左 / 右` 翻页，`BACK` 返回上一级。
- 地区选择页顶部可开启“半小时自动更新”。默认关闭；设置会随用户状态保存。
- `上`：手动刷新。未来页使用 `上 / 下` 浏览 15 天预报。
- `BACK`：在地区选择中返回上一级；主界面退出应用。
- X4 Pro 可点击城市名、自动更新开关、地区行、翻页区、右上角“更新”和底部页面栏；支持滑动翻页和上下滑动未来预报。

自动更新关闭时，应用只在进入应用、切换城市或用户手动刷新时联网。开启后，每 30 分钟通过同一个固定路由更新一次；地区选择页打开或已有请求进行中时不会重复请求。自动更新开启期间，主界面右上角的“更新”入口会隐藏；关闭后恢复手动更新。

## 看门狗

天气正文解析、地区列表解析和完整页面绘制都通过同一个长回调保护器执行。每次回调先调用 `ctx.budget:extend()` 把当前回调的截止时间推到 11 秒后（单个回调最长 30 秒）；循环中的检查点按照墙钟时间合并，最多每 1 秒再调用一次 `extend()`。应用另外保留 9 秒绝对预算，不能依靠无限续期占用设备。

回调成功时直接返回，只清理 Lua 侧临时引用。解析结果先保存在局部变量中，成功完成后才一次性写入 `ctx.state`。
