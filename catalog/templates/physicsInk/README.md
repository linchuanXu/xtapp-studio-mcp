# 受力图说

十五则高中力学与简单电路。目录用细线分行，当前则反色。点开后上半页当场画物块、斜面、力的箭头或回路，下半页是口语命题和分步说明；选中一步用圆角黑底。点图或点某一步，会重绘并加粗对应的力或元件。

力用带箭头的线表示，不在运行时排公式。图上标出力名和元件，高亮用加粗描边加小方块，方便墨水屏辨认。

- **上下 / 上滑下滑 / 点目录**：选择一则。
- **OK / 点图**：高亮下一步；最后一步再按回到全图。
- **点某一步**：高亮该步对应的力或元件。
- **左右**：换上一则 / 下一则。
- **点顶栏〈 返回 / BACK**：返回目录。目录页 BACK 退出应用。
