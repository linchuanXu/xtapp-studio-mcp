# 三国杀·墨战

离线竖屏 480×800 的 2v2 卡牌对战 XTApp。支持主界面、一次换牌、四席回合、杀/闪/桃/决斗/顺手/无中、装备、AI 行动、杀与决斗的玩家响应、濒死救援、队伍结算和再开一局。

## 对局规则链

这是一个为离线 2v2 设计的核心规则集，而非宣称覆盖官方全部武将和扩展。每个存活角色的回合明确经历：准备 → 判定 → 摸牌 → 出牌 → 弃牌 → 结束。当前没有延时锦囊时，判定阶段仍会被状态机显式经过。

玩家的主动使用统一经过三步：

1. 点击手牌选中；
2. 对于杀、决斗、顺手牵羊，点击合法目标（杀受攻击距离与每回合一次限制）；
3. 点击“确认”后才移出手牌并进入结算；可随时取消。

杀会等待闪的响应后再造成伤害；决斗会在双方无法继续出杀时造成伤害。伤害、装备减伤、濒死、桃救援和阵亡均由同一局内状态推进，体力、手牌数、装备和当前阶段实时显示在四席战场上。
