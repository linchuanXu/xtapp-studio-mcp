# 雾港遗书

面向 X4 Pro 的原创单人剧本杀。玩家以临时调查员身份，在暴雨封港前调查钟楼命案。

## 核心玩法

- 在钟楼、潮汐仓与旧邮局收集三条核心物证；核心物证不足时不能提交推理。
- 分别审问四名嫌疑人；每份证词都与时间线、动机或不在场证明相关。
- 在证据板依次锁定凶手、手法与动机，并在最终对质中选择是否提交完整指控；错误指控、手法不足、动机偏差均有不同结局与复盘。
- 点击正文推进，点击底部选项行动；长按任意位置打开线索簿和最近记录。
- 单局位置、已读记录与线索保存在 `ctx.state.mist_harbor`，退出后由宿主恢复。

本作的故事、角色、线索与文本均为原创；未使用第三方剧本、人物或素材。

## 美术

场景、人像、物证与商店封面已按 [ASSET_PLAN.md](ASSET_PLAN.md) 生成原创线稿并编码为 1bpp XIC。换稿：替换 `raw/` 同名 PNG 后运行 `encode-mist-harbor-assets.mjs`，再重建 catalog。
