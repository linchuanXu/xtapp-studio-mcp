# 清河问道

X4 Pro 触屏专用的原创水墨修仙图文游戏。第一卷「清河疫火」围绕阿梨、沈照、霜枝三条调查线、案图拼合、钟楼夜承诺、安全信号与上台确认展开；第二卷「云岚外门」用有限药材和人情处理药园、禁地、夜巡急报；第三卷「筑基前夜」把药法、旧阵和兽道收束为最终筑基抉择。没有日程刷取或按键操作。

## 长线状态

- 第一卷的六个结局会写入持久行记；重开第一卷不会清除它们。
- 若完成三处案图拼合、钟楼夜承诺与三人听审准备，可解锁第六个「案卷」结局；它会把完整案图写入跨卷行记。
- 若取得清河名簿，玩家选择先守住“名字”、旧档、药方或霜枝，也会在跨卷行记留下不同的后果文字。
- 第一卷结局会解锁第二卷，第二卷结局会解锁第三卷；每卷以新的有限资源和关系状态开始。
- 每卷首次完成会获得一次悟性；第一卷成为炼气外门候补，第二卷根据去留评议获得药圃、禁地、云涧或留察职位，终卷完成后筑基为云岚行走。重复游玩不会重复刷取悟性。
- 每次结局都会将三人的当前关系沉淀为持久缘分；第二、三卷从这些缘分继续发展，只有重开第一卷会以新的当卷关系重新开始。
- 进度由运行时 `ctx.state.qinghe` 保存；离开后由宿主恢复。

## 怎么玩

- **点画面/正文区**：翻完当前节点的分页正文；读完后底部出现选项。
- **点选项**：推进剧情。同一屏最多 4 个选项；单选项也可点正文区继续。
- **长按**：打开或关闭行记（境/位/悟、药与人情、卷章、结局、当卷关键选择标签、三人关系气质）。
- 顶栏只显示章节与关系气质（或上一选择的余波句）；数值细节在行记里。
- 本作仅支持 X4 Pro 触屏；进度写入 `ctx.state.qinghe`，退出后由宿主恢复。

## 素材

原创水墨横图（约 1750×900）保存在 `raw/`，经 **50% 强度 Floyd–Steinberg** 与 XIC 编码写入 `assets/`（场景/立绘 **448×230**；图标 128/64）。运行时按 **448∶230 等比** 装入可用画幅，不再压扁：

| key | 用途 |
| --- | --- |
| `bg_village` / `bg_shrine` / `bg_path` / `bg_gate` | 卷一基础场景 |
| `bg_bell` / `bg_medicine_hall` / `bg_archive` / `bg_well` | 钟楼、药堂、档房、废井 |
| `bg_garden` / `bg_forbidden` / `bg_cloud_stream` / `bg_council` | 卷二药园、禁地、云涧、评议 |
| `bg_vein` / `bg_pharmacy` / `bg_array` / `bg_cages` | 卷三矿脉、药室、阵盘、笼门 |
| `char_ali` / `char_shenzhao` / `char_linghu` | 三人立绘 |
| `app_icon_l` / `app_icon_s` | 应用图标 |
| `cover-store.jpg` | Mock 商店封面 |

题材借用“凡人由平凡处踏入修行”的母题，但不使用《凡人修仙传》的角色、地名、剧情、文本、美术或商标。
