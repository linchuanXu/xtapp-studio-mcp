# 城镇大亨

为 X4 Pro 横屏创作的 2–8 人触屏本地多人地产经营游戏。

## 操作

设备放在桌中央。设置阶段点击玩家头像，可以用屏幕虚拟键盘改英文名、左右切换头像；每回合先确认交接，再由当前玩家点击掷骰。默认的轻松局只保留购买、收租、升级和事件；经典局提供完整资产经营。进行中可从右上角菜单选择"返回主菜单"暂存本局，封面会显示"继续游戏"入口；下次打开仍可回到同一决策点。

## 完整玩法

- 支持 2–8 人；轻松局可选 12、16 或 20 轮，结束后按净资产排名。
- 轻松局没有竞拍、交易、抵押、债务整理或玩家淘汰，拒绝购买即可领取该地产价格一半的市政补贴。
- 轻松局的任意自有地产都可直接升级至二级；车站与设施使用固定租金。
- 轻松局资金不足时自动出售最低价值资产，仍不足则支付现有现金，不会出现负数。
- 轻松局交通管制站只需选择支付 50 或休整一回合，对子不会改变玩家顺序。
- 经典局保留公开竞拍（起拍价 1 元）、完整街区、均衡三级建设、交易、抵押、债务与破产。
- 税、事件罚款和检查站费等交给银行的钱会累积进城市发展基金，踩到人民公园时一次性领取。
- 所有模式的回合、待确认操作、随机种子和牌堆游标都随应用状态恢复。
- 右上角菜单可"返回主菜单"暂存本局，封面出现"继续游戏"；对局恢复后回到同一决策点，"新开一局"会清空暂存。

本游戏仅面向 X4 Pro 触屏；不读取按键输入，也不依赖联网服务。

## 开发结构

模式规则、竞拍、地产、交易、事件、计分、触摸布局和绘制相互分离。编辑期使用 `domain/*.lua`，发布时由 Studio 展开为单入口 Lua。绘制层用 `g:circle` 与 `g:rect` 拼出圆角按钮、卡片与棋盘格（1bpp API 只有这两种图元），保持热区与布局坐标不变。
