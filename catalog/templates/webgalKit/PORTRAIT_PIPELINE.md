# 前景立绘管线（1bpp）

这套流程适用于所有前景角色，不依赖某一张图或某一部作品。

1. 准备完整角色 PNG：角色四周留白、无场景、无投影。剧情舞台默认用半身/胸像构图；若源图是全身图，在编码时显式提供 `portraitFrame`，不要把整个人缩进一个角色槽位。
2. 把背景图和角色细节统一以 Floyd–Steinberg **50%** 强度转为 1bpp。人物可使用更高的保细线阈值，保证脸部线稿不会在缩放后消失。
3. 角色背景做成透明：从图像四边能连通到的纸白设为透明；被线稿围住的白脸、白衬衫和高光保持不透明的白。打包器保留源图的透明通道，运行时直接画这一张图，不需要额外的剪影层。
4. 在 XTApp Studio 中重新生成素材并检查预览。
5. 在实际预览中检查单人、双人和三人场景：脸部/衣物不能透出背景，角色边缘不能露出原图背景。
