# 墨闻

面向 X4 Pro 的真实新闻头条阅读器。应用通过服务器代理使用阿里云市场“新闻查询”商品，提供综合、国内、国际、财经、科技五个频道；数据源约每 5 分钟更新。

## 操作

- `上 / 下`：选择上一条或下一条头条；跨过当前 20 条时自动请求前后页。
- `左 / 右`：切换频道并请求该频道第一页。
- `OK`：进入当前头条的聚焦阅读页；阅读页内 `上 / 下` 切换头条。
- `BACK`：从聚焦页返回列表；列表页退出应用。
- 触屏可直接点击频道、头条、上一页、下一页和刷新；刷新始终回到当前频道第 1 页。

应用首次进入时自动请求一次，但不会定时刷新。之后只有切换频道、翻页或点击刷新时才请求一次 Demo；点击刷新会回到当前频道第 1 页。服务器按“频道 + 页码”缓存 5 分钟，与上游刷新频率一致，避免浪费付费调用次数。

## 数据边界

该商品文档声明可返回标题、摘要、正文、来源、发布时间、图片和原文链接。真实调用验证表明，当前响应稳定提供标题、频道、来源、发布时间、图片标记与原文链接，但摘要和正文字段为空。因此本应用诚实定位为“实时头条阅读器”，不会伪造正文或混入其他免费新闻源。

设备端只保存当前 20 条受限文本记录，不下载新闻图片，也不会打开原文链接。图片标记仅显示该头条在上游是否附图。

## 联网路由

```text
墨闻 index.lua
  └─ GET http://193.112.174.92:28473/demo/news/feed/xtapp?category=<固定频道>&page=<页码>
       └─ Demo 服务 POST https://jmxwxxcx.market.alicloudapi.com/news/channel
       └─ Demo 服务 POST https://jmxwxxcx.market.alicloudapi.com/news/list
            └─ 阿里云市场付费新闻数据源
```

XTApp Lua 在 Manifest 声明 `net` 后用 `ctx.net:request()` 异步执行 `http://` GET，请求结束时回调处理结果，退出时 `job:cancel()`。HTTPS、POST 与鉴权必须走受限服务端代理；HTTP 链路及 Lua、Manifest、前端、AI 不得承载密钥或敏感数据。

服务器只接受 `all/domestic/world/finance/technology` 五个频道键和数字页码，不提供任意 URL、任意上游路径或任意鉴权头转发。阿里云凭证只存在于服务器环境变量中。

设备协议首行为 `XTAPP_NEWS_V1`，随后是 `category/page/total_pages/total_count/updated` 元数据和最多 20 行 TAB 分隔的 `item` 记录。
