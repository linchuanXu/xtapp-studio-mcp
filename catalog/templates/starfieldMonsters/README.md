# 《星野录》

可审计、可编辑的 XTApp API 2.x 原创怪兽收集 RPG 工程。

- `manifest.json`：标准 XTApp 清单；目标为 X4 Pro 竖屏。
- `index.lua`：持续扩展中的原创 RPG，含四地区探索、双招式战斗、捕获、三席队伍、战斗换人、采集、委托、制作、治疗、图鉴、成长与试炼。
- `assets/mon_*.png`：独立白底黑线小精灵 PNG 源图；对应 `.xic` 版本由游戏在标题与战斗页以原尺寸加载。整屏氛围图不进入设备运行时。

## X4 操作

- 探索：方向键移动；OK 与当前位置交互；BACK 打开图鉴。
- 战斗：左右切换「招式 / 捕获 / 逃离」；OK 确认；BACK 返回探索菜单。
- 触控：地图区域按下可移动；战斗页按下方整行按钮可选择行动。

## 原创边界

这是借鉴“怪兽收集 RPG”类型结构的原创作品。这里的生物、名称、属性、地图、文案、数值、绘制和代码均为 Studio 编写；不使用宝可梦或外部参考项目的角色、素材、数据、文本或代码。

精灵素材以图像生成工具于 2026-07-24 为本项目原创生成：白底、粗黑线、无场景、无灰阶和无文字。PNG 源图与 128×128 XIC 版本都保存在 `assets/`；先接入三只初始伙伴，余下遭遇生物继续沿同一规范补齐。

## 当前切片

从三个初始伙伴中选择其一，依次进入苔光小径、雾苔湿地、碎页林地、风化山坳和旧天文台径，在草地里遭遇 `苇芽`、`灯尾獭`、`菌羽鸟`、`砾星`、`浮鳍`、`溪石螈`、`刺铃蕨`、`铁鸣蟋`、`纸舟鳐`、`苔铠獾`、`雾铃蜗`、`拾砂鸻`、`针果狸`、`漂壳蟹`、`织星蛾` 等原创生物。碎页林地有独立遭遇表、采集点、治疗点与通往山坳的出口，译页师顾铭会给出一次性可恢复的护符/材料支线。织星蛾在天文台径出现，漂壳蟹在潮纹库湾出现；击败守门人后还会开放终局后的镜潮堤岸，其高阶遭遇、星屑采集和潮汐记录员洛棠的奖励为完成主线后的队伍培养提供去处。五位署名巡野员、渡桥考官陵桥、七位驻站医师、观测员兰阅、译页师顾铭、记录官陆卷、后勤员沈砚、台长玄书、守门人潮屿与记录员洛棠都承担试炼、恢复、委托或终局职责。击败天文台记录守卫后，潮纹库湾会开启；该路线有独有试炼、采集点和潮纹守门人终局战。玩家可以战斗、捕获、治疗、查看图鉴、组成最多三只同行队伍，并完成苔光、湿地、渡桥、山坳与天文台五枚前置巡野印后进入天文台。

星港区域另有巡野委托板、采集点和后勤站：完成采集、捕获和试炼会推进可领取的委托；星露与苔纤维可制作战斗中使用的星露药。

获得天文台钥印后，委托板会显示七日周报目标。每天由一个主目标和两项野外行动构成，采集、捕获、制作、巡野复战、星轨远征和星屑收集都会推进相应进度；全部完成后交付，刷新地图采集点并进入下一日。训练师首通会给高额奖励，后续可复战并给较低报酬，使第二周及以后仍能完成试炼日程。天文台首领后，周报台会开放三条可重复、各有两段连续遭遇的星轨远征（苔风回声、河床折光、失焦星图）；每条都有独立敌人、难度、首胜记录与星屑报酬，因此第六日也可重复完成。

当前包含 18 只可遇见生物、4 条可成长形态和 38 个原创招式数据：苇芽会成长为苇花，灯尾獭会成长为光舷兽，纸舟鳐会成长为舟潮魟，苔铠獾会成长为冠苔獾。所有可捕获形态与四个成长形态各有独立白底黑线 PNG/XIC；图鉴分四页显示，避免把素材缩小到 X4 上难以辨认。它们都以三个可解释属性（芽 / 潮 / 辉）构成克制环，不使用现有作品的角色、素材、数值表或设计。

图鉴捕获数达到 3、6、10 只时，可在委托板领取额外巡野印与捕获器。远征和山坳得到的星屑也能在后勤站压制成两枚星纹捕获器，令收集、远征与资源制作构成可重复循环。

后勤站还有第四类战术道具「星屑护符」：消耗 2 份星屑与 1 份苔纤维制作；战斗中激活会立即为当前伙伴建立 7 点护幕。捕获器、星露药、星纹捕获器与星屑护符因此各自承担捕获、恢复、资源转化与防御节奏的不同选择。

委托板另有「整周研究」页：新物种采样、同行默契、星轨复测、星屑标本会跨七天累计；完成后领取奖励，并在一周结束时刷新。这使每日采集、遭遇、试炼和远征同时服务于长期目标。

委托板的第三页是「田野课题」。玩家可在潮线采样、苔域编目、辉光默契中选择一条研究路线；分别通过捕获潮属性伙伴、采集苔纤维或完成战斗推进。每条课题的选择、进度和归档奖励都会持久保存，完成后可改选另一条，因此同一周内的行动不只是服务于固定的日程计数。

委托板的第四页是「地区调查」。七张路线各自要求一次采集、一次战斗和一次捕获；三项现场记录都完成后会自动归档，并给出巡野印、捕获器与星屑。它与每日周报、田野课题并行，鼓励玩家在整周内轮换探索区域。

路线威胁会逐步提高：苔光小径为 Lv.2–3，雾苔湿地为 Lv.3–5，山坳为 Lv.4–6，天文台径为 Lv.5–7，潮纹库湾为 Lv.6–8。完成周报后，野外与星轨远征会继续提高等级（最高 Lv.12），让成长、进化和资源循环在后续周次仍有意义。

每只生物的第二招式不只是另一项伤害数值：部分会恢复体力，部分会为下一次受击建立护幕。护幕会在承受攻击后消耗，配合三席同行与换人可形成持续的队伍构筑选择。

治疗站会恢复同行体力并把捕获器不足的库存补足到 5 个，但不会覆盖通过委托、远征、图鉴或制作得到的额外捕获器。

潮纹库湾必须在天文台首领后进入；通过库湾试炼再击败潮纹守门人，会获得终局潮印、巡野印、捕获器与星屑。这是首领后路线的明确终局目标，而非一次性结尾画面。
