# 羊狼过河

内置官方游戏，来自用户提供的 XTApp Studio 项目快照。

这是一款面向 X4 Pro 的 50 关逻辑游戏：每关根据左右两岸的羊、狼数量和当前船容量，输入本次过河的人数。规则会阻止让任一岸的羊被狼压制的移动；进度、当前关卡和成就都保存在设备本地。

## 操作

- 在主界面点“开始挑战”进入关卡。
- 点按输入格后输入数字，点“过河”提交；按键可用于翻页、确认和返回。
- 可查看规则、通关路线与已获得的成就。

## 工程结构

- `data/`：关卡目录与解法数据。
- `domain/`：状态、规则、界面和应用输入协调。
- `assets/scene_background.xic`：原项目的 480×800 单色场景背景。

源码和素材均保留为可编辑的 Studio 标准应用工程。
