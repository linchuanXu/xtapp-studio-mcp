# 自选行情

在设备上保存自己的港股、A 股、美股自选代码，并逐个拉取真实行情。默认包含腾讯、美团、贵州茅台和苹果；可用内置代码编辑器加入任意代码，保存状态会跟随应用留在设备上。

```text
GET http://193.112.174.92:28473/demo/stock/xtapp?symbol=00700
GET http://193.112.174.92:28473/demo/market/detail/xtapp?kind=a&symbol=sh600519
GET http://193.112.174.92:28473/demo/market/detail/xtapp?kind=us&symbol=AAPL
```

## 操作

- 右上角“刷新”或 `OK`：从第一只开始逐条更新，避免同时发起多次付费请求。
- 右上角“添加”：键盘会按市场自动收敛。港股直接使用大号九宫格；A 股先选 `沪 SH / 深 SZ / 北 BJ`，再只显示数字；美股才显示完整字母键盘。也可用方向键移动键盘焦点、`OK` 输入当前键。
- 键盘内“删除”回退一位，“完成”保存并刷新。港股必须为五位数字；A 股为 `sh` / `sz` / `bj` 加六位数字；美股为最多八位大写字母或数字。
- 右上角“删除”：删除当前左侧标记的自选，必须在确认页再次选择“删除”。列表支持 `上 / 下` 选择，`左` 删除、`右` 添加。

## 联网与数据边界

设备只调用固定 HTTP GET 路由，凭据留在服务器端。Lua 用 `ctx.net:request()` 发起一个报价请求，回调收到结果后才请求下一只，因此不会并发刷接口。返回内容是 `XTAPP_STOCK_V1` 文本协议。HTTP 链路仅可传公开证券代码，禁止传输密码、令牌或个人信息；行情仅供展示，不构成投资建议。
