# 支付宝收支提醒

面向 X4 Pro 的竖屏触控财务摘要 Demo，重点不是支付操作，而是让用户快速看懂今日收支、即将发生的扣款和异常风险。

- 今日页默认遮挡金额，轻触“眼睛”区域才在主应用内展开；退出后仍保留用户的隐私选择。
- 账单页按时间展示本地样本，可上下滑动浏览。
- 待办页汇总还款和自动扣款，支持轻触标记已处理。
- 安全页可切换金额遮挡并把伴生页面设为系统锁屏。
- 锁屏永远不显示完整金额、支付方式、账户尾号或具体商户，只显示付款事项数量、时间窗口和预算状态。

全部数据均为本地 TSV 演示样本；应用不连接支付宝账户、不保存支付凭据，也不提供真实付款能力。应用只面向 480×800 竖屏 X4 Pro，以触摸为唯一操作路径。

所需素材 key 为 `app_icon_s`、`app_icon_l`、`splash`、`brand_mark`、`feature_scene`、`icon_wallet`、`icon_bill`、`icon_reminder`、`icon_shield`、`icon_eye` 和 `icon_check`。
