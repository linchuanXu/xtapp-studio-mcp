# 阿里云 AI 成本与容量看板

面向 X4 Pro 的竖屏纯触控离线演示应用，将阿里云百炼 / 通义模型团队最常看的费用、模型用量、推理容量和预算告警压缩为四个可扫读页面。

## 交互

- 轻触顶部标签或左右滑动，在“费用 / 模型 / 容量 / 告警”之间切换。
- 费用页可切换近 7 日与近 30 日口径。
- 模型页可轻触模型行，查看该模型的 Token、成功率、延迟和成本。
- 容量页可在华东 1、华北 2 两个区域间切换。
- 告警页可开关三条告警规则，并通过 `- ¥500` / `+ ¥500` 调整演示预算。

## 数据与安全边界

- 所有数字均为内嵌的虚构样本，用于表达看板效果，不代表真实价格、账户或服务状态。
- 应用不声明网络权限，不联网，不读取 API Key、AccessKey、云账号或本机文件。
- 资源键由素材管线提供：通用键 `app_icon_s`、`app_icon_l`、`splash`、`brand_mark`、`feature_scene`，以及 Manifest 中列出的页面图标键。
- 目标设备为 X4 Pro，逻辑画布为竖屏 480×800，交互方式为 `touchOnly`。

## 页面意图

1. **费用**：快速回答“本期花了多少、主要花在哪、会不会超预算”。
2. **模型**：对比三个模型的调用规模，并下钻到单模型质量与成本。
3. **容量**：查看区域实例、GPU、端点和峰值余量，判断是否需要扩容。
4. **告警**：集中管理预算、GPU、错误率三类值守规则，形成处置入口。
