## 贡献约定

- 只记录已经在 Studio 或真机上验证过的做法；不确定的内容标记为“待验证”。
- 契约事实以本插件打包的公开知识索引为准，经验不能替代契约。
- 公开素材必须确认许可证、署名和再分发条件；不能把来源不明的图片或品牌素材提交进公共仓库。
- 不提交用户项目、私有素材、密钥、设备固件或未经授权的二进制文件。
- 经验应优先给出可复制的命令、目录结构和检查结果，避免只写主观评价。
