# XTApp 视觉设计经验

这里先放共创者后续可以补充的设计方向。每个方向都应逐步沉淀：适用产品、画布尺寸、布局比例、边框规则、素材处理、交互反馈、示例工程和验证截图。

## 经验主题占位

- [ ] 像素风：网格、像素尺寸、硬边缘、有限色阶、放大与抖动规则。
- [ ] 极简电子纸：黑白层级、留白、信息密度、分隔线和刷新成本。
- [ ] 卡片与面板：圆角、描边、内边距、阴影替代方案和嵌套层级。
- [ ] 仪表盘：数字层级、单位、状态颜色转黑白符号、首屏信息优先级。
- [ ] 游戏界面：角色/背景分层、按钮命中区、选中态和动画帧预算。
  动画快慢、每帧画法耗时和「游戏卡、显示慢」的排查已写进作者指南「墨水屏动画与游戏：流畅度和速度」（`search_xtapp_knowledge` 可查）；这里只补视觉设计方面的经验。
- [ ] 插画与 emoji：轮廓保留、白底合成、字体授权、缩小后的识别度。
- [ ] 横屏与竖屏：共同组件、断点、方向切换和 X4 Pro/Classic 差异。
- [ ] 锁屏画面：单帧背景、低刷新设计、与主程序状态的共享边界。

## 每篇设计经验应回答

1. 目标设备和真实画布尺寸是什么？
2. 边框宽度、内边距、基线和对齐规则是什么？
3. 哪些内容应做成 XIC，哪些内容应由 Lua 动态绘制？
4. 黑白转换后最容易丢失什么细节？如何处理？
5. 按键、触摸和焦点状态如何表达？
6. 在 Studio 和真机上如何验证，失败时如何回退？

新增文档建议命名为 `experience/design-<topic>.md`，并在本页目录中登记。占位项完成验证后再改为链接，避免把未验证的审美偏好写成契约。
